# Digital Image Processing

## HSI Filter Practical

This repository contains a complete practical using the supplied birds-and-flowers image and six spatial filters:

- Averaging
- Gaussian
- Maximum
- Median
- Minimum
- Weighted Average

The practical converts the input image from RGB to HSI, applies each filter to the intensity channel, and converts the result back to RGB.

### Project files

See the `HSI_Filter_Practical/` folder for the Python source code, input image, requirements, and generated output images.

### Run

```bash
pip install -r HSI_Filter_Practical/requirements.txt
python HSI_Filter_Practical/hsi_filters.py
```
